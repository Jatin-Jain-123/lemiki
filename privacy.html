Privacy Policy

Last updated: 10 October 2026

Lemiki™ is made by Jatin Jain. It is a desktop pet app plus a VS Code extension.

The short version

Lemiki collects nothing. Nothing you do leaves your computer.

What Lemiki uses, and where it goes

  • Editor events. The VS Code extension notices things like "you started typing", "you saved a file", "a build passed" or "tests failed". It sends only the name of the event (for example build_success) to the Lemiki desktop app.
  • Where they go. Only to 127.0.0.1, which means your own computer. They are never sent over the internet.
  • What is never sent: your code, file names, folder names, terminal output and command text.
  • Settings. Lemiki saves your pet's size and visibility in a small file on your computer. It also saves a file that tells the extension how to start the app (.lemiki/launch.json in your home folder).

What Lemiki does not do

  • No accounts, sign-ins or personal information.
  • No analytics, tracking, advertising or cookies.
  • No data is sold or shared, because none is collected.

Children

Lemiki collects no data from anyone, including children.

Changes

If this ever changes (for example, if an optional feature needs the internet), this page will be updated before the change ships, and the feature will be off unless you turn it on.
